FmButton = 按钮基座（尺寸 / 状态 / focus ring / 触控区）唯一定义处；FmCard = 容器（圆角 / 阴影 / 内边距 / 标题与分隔）唯一定义处


U-2 数量与归属不变
	
第一批 8 个 SFC 与《30》§4.4 序号 1/2/4/25/26/27/28/29 一致，未新增共享基座


U-3 规范条目承载
	
FmIconButton 的基座规则不另立一套，其卡只写差异（§3.2 复用关系字段）


U-4 引用基座验收编号
	
FmIconButton 验收项引用 FmButton 的 B-01～B-10 编号；继承结论不重复实测、另测差异态


U-5 别名按基座归属
	
--fm-btn-* 只在 FmButton 名下定义；FmIconButton 复用同名别名，不另起 --fm-iconbtn-bg-* 等重复定义（仅尺寸 / 图标尺寸两类独有别名）


U-6 不产生新组件
	
P-01 / P-04 承接只引用现有组件数据位（§4）；FmPagination 属 C-04，第一批不涉及
1.5 全局 i18n 与数据边界（对第一批生效）
组件内置文案 key 统一 fm.<comp>.* 前缀；本步不产出译文文件（译文属 Q-10 口径），仅登记 key 清单与回退规则（缺失回退 zh-CN）。
所有组件不直接访问 Dexie / IndexedDB / Repository；数据一律经 props 传入、结果经 emit 传出。
数量 / 文案不写死；文案长度自适应不截断不挤压（《30》§4.3 C-01）。
