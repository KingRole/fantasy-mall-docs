## 2. 页面模板分类与复用关系

### 2.1 分类原则

1. **按信息架构与交互骨架归类**，不按业务页面一一建模板：同类页面共用一套骨架，通过组件组合与数据位差异适配具体页面。
2. **双端各一套独立布局**：同一模板族含 PC 变体与手机变体，二者是独立布局（非缩放），共用同一份 Token 与组件语义（《19》§1.1 /《03》A.4）。
3. **前台 / 后台分族**：前台重营销与交易转化，后台重结构化数据与操作确认；共用品牌 Token，不共用布局骨架。
4. **不产生新组件**：模板只组合既有 36 SFC + 统一规范条目；P 组 5 项仍由现有组件承接，不新增模板级组件。
5. **模板数量最小化**：足以覆盖 70 套视图即可，避免过度切分；每个模板族须给出覆盖页面清单（§4）与对账（§4.3）。

## 6. 设计顺序与分批交付计划

### 6.1 设计顺序原则

1. **先高复用、后低频**：首页 / 列表 / 详情等高频骨架优先，便于尽早暴露 Token 与组件组合问题。
2. **先前台、后后台**：前台模板同时服务双端视觉审阅；后台复用通用组件，后置降低返工。
3. **每批含双端**：每个模板族同时给 PC + 手机布局，避免单端先行导致另一端返工。
4. **每批送审**：按 ①-2 两段闸门经验——每批产出后提交，GPT 通过即启动下一批；全量完成后单独送审、单独确认（①-3 X-15）。
5. **视觉先行**：进入正式模板规范前，先出供审阅视觉稿（本轮首批），确认视觉方向后再固化规范。

### 6.2 分批计划（13 族分三批 + 收尾核验）

| 批次 | 模板族 | 覆盖页面 | 交付物 | 视觉稿 |
| --- | --- | --- | --- | --- |
| **批次一（前台核心）** | TP-01 首页 / TP-02 列表 / TP-03 详情 | F-01、F-02/03/05/14/15/16、F-04 | 模板规范卡（骨架 / 双端布局 / 组件组合 / 数据位 / 验收）+ 自检记录 | **本轮首批视觉稿**：PC 首页、手机首页、商品详情双端、后台管理列表（后两者为方向示例） |
| **批次二（前台交易与账户）** | TP-04/05/06/07/08/09 | F-06～F-20 + 地址子页 | 同上 | 批次二视觉稿（启动后产出） |
| **批次三（后台）** | TA-01/02/03/04 | A-01～A-14 | 同上 | 批次三视觉稿（启动后产出） |

## 8. 可复现自检脚本（V1.1 新增）

> 运行方式：保存为 `.py` 于项目根目录运行；输出应与 §8.1 stdout 逐字一致。脚本同时检查六张 PNG 真实存在于 `previews/screenshots/`。

```python
import pathlib
ROOT = pathlib.Path('.').resolve()
r = (ROOT/'docs/47-阶段一第三步-首批页面模板视觉方案说明.md').read_text(encoding='utf-8')
sdir = ROOT/'previews/screenshots'
pngs = sorted(p.name for p in sdir.glob('*.png')) if sdir.exists() else []
checks=[]
def ck(n,c): checks.append((n,bool(c)))
# A 版本与结构
ck('A1 V1.1留痕','V1.0 → V1.1' in r)
ck('A2 六张截图小节','2A. 六张真实渲染截图' in r)
# B 六张PNG真实存在
for key in ['01-F01-PC','02-F01-手机','03-F04-PC','04-F04-手机','05-A02-PC','06-A02-手机']:
    ck('B-'+key, any(key in p for p in pngs))
ck('B6 共6张', len(pngs)==6)
# C 每张标注编号/端/模板族（表格）
for x in ['F-01 商城首页','F-04 商品详情','A-02 后台商品管理','TP-01','TP-03','TA-02']:
    ck('C-'+x, x in r)
# D 颜色核验
for hx in ['#EC3C3E','#FB4D4C','#FC5A57','#C2332E','#FD9A95']:
    ck('D-'+hx, hx in r and '合法' in r)
ck('D6 只核验不改Token','只核验' in r and '未新增' in r)
# E 技术真实性
ck('E1 element.screenshot','element.screenshot' in r)
ck('E2 不拼凑','未拼凑' in r and '未替换' in r)
ck('E3 gallery索引','gallery.html' in r)
# F 边界
ck('F1 不进①-4','①-4' in r)
ck('F2 已通过文档零写入','零写入' in r)
passed=sum(1 for _,v in checks if v)
for i,(n,v) in enumerate(checks,1):
    print(f"[{'OK' if v else 'FAIL'}] {i:02d} {n}")
print(f"TOTAL: {passed}/{len(checks)} PASS")
```
